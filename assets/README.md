# Media assets

Place new photos in `assets/images/` and videos in `assets/videos/`.

## Adding an image
1. Save the file here (e.g. `assets/images/project-name.jpg`).
2. In `index.html`, reference it:
   `<img src="assets/images/project-name.jpg" alt="Description" loading="lazy">`
3. Prefer existing card/media CSS classes so sizing stays consistent.

## Adding a video
1. Save to `assets/videos/`.
2. Wrap in a `.media-frame` container (styles live in `index.html`).

## Resume
Place your PDF at the project root as `resume.pdf` (already linked from Contact).
